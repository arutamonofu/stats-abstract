# Свойства

| Свойство          | Значение                                                                                                                                                          |
| :---------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Тип переменных    | $X$ — количественная<br>$Y$ — количественная                                                                                                                      |
| Что измеряет      | Доля дисперсии зависимой переменной ($Y$), которая объясняется независимыми переменными ($X$) в рамках регрессионной модели. Качество подгонки (goodness of fit). |
| Диапазон значений | $[0; 1]$                                                                                                                                                          |
| Условия           | - Линейность связи между переменными.<br>- Независимость ошибок.<br>- Нормальное распределение ошибок.<br>- Гомоскедастичность.                                   |
| Обозначение       | $R^2$                                                                                                                                                             |

# Вычисление

$$1 - \frac{SS_{res}}{SS_{total}}$$
Где:

- $SS_{res} = \sum{(y_{i} - \hat{y}_{i})^2}$ — сумма квадратов ошибок регрессии;
- $SS_{total} = \sum{(y_{i} - \bar{y}_{i})^2}$ — сумма квадратов отклонений наблюдений от среднего.

Альтернативная формула № 1:

$$\frac{SS_{reg}}{SS_{total}}$$

Где $SS_{reg} = \sum{(\hat{y}_{i} - \bar{y})^2}$ — сумма квадратов отклонений регрессии от среднего.

Альтернативная формула № 2:

$$r^2$$

Где $r$ — коэффициент корреляции Пирсона.

# Пример

Исследуется, насколько хорошо затраты на рекламу (в тыс. долларов) объясняют объём продаж (в тыс. штук) для продукта. Были собраны данные за 5 месяцев:

Затраты на рекламу ($X$): $[10, 15, 20, 25, 30]$
Объем продаж ($Y$): $[30, 40, 45, 55, 60]$

Была построена линейная регрессионная модель: $\hat{y} = 16 + 1.5x$.

Вопрос: какую долю дисперсии объёма продаж можно объяснить затратами на рекламу с помощью линейной регрессионной модели?

Решение:

1. Рассчитаем $\bar{y}$:
	- $\bar{y} = \frac{30 + 40 + 45 + 55 + 60}{5} = 46$

2. Рассчитаем $\hat{y_{i}}$ $(y_i - \hat{y}_i)^2$, $(y_i - \bar{y})^2$:

| $x_i$ | $y_i$ | $\hat{y}_i$ | $(y_i - \bar{y})$ | $(y_i - \hat{y}_i)$ | $(y_i - \bar{y})^2$ | $(y_i - \hat{y}_i)^2$ |
| :---- | :---- | :---------- | :---------------- | :------------------ | :------------------ | :-------------------- |
| $10$  | $30$  | $31$        | $-16$             | $-1$                | $256$               | $1$                   |
| $15$  | $40$  | $38.5$      | $-6$              | $1.5$               | $36$                | $2.25$                |
| $20$  | $45$  | $46$        | $-1$              | $-1$                | $1$                 | $1$                   |
| $25$  | $55$  | $53.5$      | $9$               | $1.5$               | $81$                | $2.25$                |
| $30$  | $60$  | $61$        | $14$              | $-1$                | $196$               | $1$                   |

2. Рассчитаем $SS_{total}$ и $SS_{res}$:
	* $SS_{total} = 256 + 36 + 1 + 81 + 196 = 570$
	* $SS_{res} = 1 + 2.25 + 1 + 2.25 + 1 = 7.5$

3. Рассчитаем $R^2$:
    * $R^2 = 1 - \frac{7.5}{570} \approx 0.987$

Вывод: примерно $98.7\%$ дисперсии объёма продаж объясняется дисперсией затрат на рекламу в рамках построенной линейной регрессионной модели.

## Python

```python
import numpy as np
from scipy import stats # Для коэффициента Пирсона r
# Для более прямого вычисления R^2 можно использовать sklearn,
# но для демонстрации SS_total и SS_res сделаем шаги вручную.

# Данные из примера
x_values = np.array([10, 15, 20, 25, 30])
y_values = np.array([30, 40, 45, 55, 60])
n = len(x_values)

print("Исследуется, насколько затраты на рекламу объясняют объем продаж.")
print(f"Данные для {n} месяцев:")
print(f"Затраты на рекламу (X): {list(x_values)}")
print(f"Объем продаж (Y): {list(y_values)}")
print("-" * 30)

# 1. Находим уравнение линейной регрессии y_hat = b0 + b1*x
# Используем scipy.stats.linregress для получения b1 (slope) и b0 (intercept)
slope, intercept, r_value, p_value, std_err = stats.linregress(x_values, y_values)
b1 = slope
b0 = intercept

print("1. Уравнение линейной регрессии:")
print(f"   b1 (наклон) = {b1:.4f}")
print(f"   b0 (свободный член) = {b0:.4f}")
print(f"   ŷ = {b0:.2f} + {b1:.2f}x")
print("-" * 30)

# 2. Рассчитываем предсказанные значения y_hat
y_pred = b0 + b1 * x_values

print("2. Расчетные значения:")
print(f"   Фактические Y: {y_values}")
print(f"   Предсказанные Ŷ: {np.round(y_pred, 2)}")
print("-" * 30)

# 3. Рассчитываем SS_total и SS_res
y_mean = np.mean(y_values)
ss_total = np.sum((y_values - y_mean)**2)
ss_res = np.sum((y_values - y_pred)**2)

# (Альтернативно) Рассчитываем SS_reg
ss_reg = np.sum((y_pred - y_mean)**2)
# Проверка: ss_total должен быть примерно равен ss_reg + ss_res
# print(f"   Проверка: SS_total = {ss_total:.4f}, SS_reg + SS_res = {ss_reg + ss_res:.4f}")


print("3. Расчет сумм квадратов:")
print(f"   Среднее значение Y (ȳ): {y_mean:.2f}")
print(f"   SS_total = Σ(yᵢ - ȳ)² = {ss_total:.4f}")
print(f"   SS_res = Σ(yᵢ - ŷᵢ)² = {ss_res:.4f}")
print(f"   SS_reg = Σ(ŷᵢ - ȳ)² = {ss_reg:.4f} (для информации)")
print("-" * 30)

# 4. Рассчитываем R^2
r_squared_formula1 = 1 - (ss_res / ss_total)
r_squared_formula2 = ss_reg / ss_total # Альтернативная формула

print("4. Расчет R²:")
print(f"   R² (по формуле 1 - SS_res/SS_total) = 1 - ({ss_res:.4f} / {ss_total:.4f}) = {r_squared_formula1:.4f}")
print(f"   R² (по формуле SS_reg/SS_total) = {ss_reg:.4f} / {ss_total:.4f} = {r_squared_formula2:.4f}")
print("-" * 30)

# 5. Вывод и проверка с r_value^2
print("5. Вывод:")
print(f"   Коэффициент детерминации R² ≈ {r_squared_formula1:.4f}")
print(f"   Это означает, что примерно {r_squared_formula1*100:.2f}% вариации объема продаж")
print(f"   объясняется вариацией затрат на рекламу в рамках данной линейной модели.")

# Для простой линейной регрессии R^2 = r^2
r_squared_from_pearson_r = r_value**2
print("\nПроверка (для простой линейной регрессии R² = r²):")
print(f"   Коэффициент корреляции Пирсона (r) = {r_value:.4f}")
print(f"   r² = ({r_value:.4f})² = {r_squared_from_pearson_r:.4f}")
print(f"   Это значение совпадает с R², рассчитанным через суммы квадратов.")
print("="*40)

# Использование sklearn для быстрой проверки
from sklearn.metrics import r2_score
r2_sklearn = r2_score(y_values, y_pred)
print(f"Проверка с помощью sklearn.metrics.r2_score: R² = {r2_sklearn:.4f}")
print("="*40)

```
