Метод отбора признаков — процесс выбора наиболее значимых переменных для модели, чтобы улучшить её точность, снизить переобучение и ускорить вычисления.

Пошаговые методы:

| Метод                                                                         | Общее описание                                                                                                                                                                                                                     |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[Метод прямого отбора\|Метод прямого отбора (forward entry)]]                | Сначала в пустую модель добавляется предиктор, объясняющий наибольшую дисперсию зависимой переменной. Затем пошагово к добавлению рассматриваются предикторы, имеющие наименьшее $p$-значение или дающие наибольший прирост $R^2$. |
| [[Метод обратного отбора\|Метод обратного отбора (backward removal)]]         | Сначала в пустую модель добавляются все признаки. Затем пошагово к удалению рассматриваются предикторы, имеющие наибольшее $p$-значение, или при исключении которых наименьшее уменьшение $R^2$.                                   |
| [[Метод последовательного отбора\|Метод последовательного отбора (stepwise)]] | Сначала в пустую модель добавляется предиктор, объясняющий наибольшую дисперсию зависимой переменной. Затем на каждом шаге рассматривается исключение и включение предикторов как комбинация методов прямого и обратного отбора.   |
