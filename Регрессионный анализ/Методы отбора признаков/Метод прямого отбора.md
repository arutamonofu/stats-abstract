Метод прямого отбора (forward entry) — пошаговый метод отбора признаков для построения регрессионной модели, начиная с пустой модели и добавляя признаки по одному.

# Свойства

| Свойство         | Значение                                               |
| :--------------- | :----------------------------------------------------- |
| Вид              | Пошаговый, обёрточный.                                 |
| Исходная модель  | Не включает ни одного признака (или только константу). |
| Действие на шаге | Добавление одного признака.                            |

# Методология

Сначала модель не содержит ни одного признака (или только константу). Затем пошагово к добавлению рассматриваются признаки (еще не включённые в модель), соответствующие одному из критериев:

* наименьшее $p$-значение (из всех еще не включённых признаков);
* наибольшее увеличение $R^2$ (при добавлении одного из еще не включённых признаков).

Метод останавливается при выполнении одного из условий:

* Все оставшиеся (не включённые в модель) признаки имеют *p*-значение, превосходящее пороговое $\alpha_{\text{in}}$.
* Дальнейшее добавление признаков не приводят к увеличению $R^2$, превосходящему пороговое.

# Пример

Представьте, что вы владелец небольшой кофейни и хотите лучше понимать, какие факторы влияют на ежедневное количество проданных чашек кофе. Это поможет вам в планировании запасов, персонала и маркетинговых акций.

Зависимая переменная ($Y$):

- Продано чашек

Независимые переменные ($X$):

1. Температура воздуха — количественная.
2. Выходной — бинарная категориальная.
3. Акция — бинарная категориальная.
4. Количество осадков — количественная.
