Метод последовательного отбора (stepwise regression) — гибридный метод отбора признаков для построения регрессионной модели, сочетающий элементы методов [[Метод прямого отбора|прямого отбора (forward entry)]] и [[Метод обратного отбора|обратного отбора (backward elimination)]] на каждом шаге.

# Свойства

| Свойство         | Значение                                                                       |
| :--------------- | :----------------------------------------------------------------------------- |
| Вид              | Пошаговый                                                                      |
| Исходная модель  | Не включает ни одного признака (или только константу).                         |
| Действие на шаге | Добавление одного признака, затем удаления одного из уже включенных признаков. |

# Методология

Модель начинается пустой (или только с константой). Затем на каждом шаге выполняются две операции:

1. К добавлению рассматриваются признаки (еще не включённые в модель), соответствующие одному из критериев:
	* наименьшее $p$-значение (из всех еще не включённых признаков);
	* наибольшее увеличение $R^2$ (при добавлении одного из еще не включённых признаков).

2. К удалению рассматриваются признаки, соответствующие одному из критериев:
	- наибольшее $p$-значение (из включённых в модель).
	- наименьшее уменьшение $R^2$ при удалении.


Метод останавливается при выполнении обоих условий:

* На этапе включения ни один признак не может быть добавлен в модель.
* На этапе исключения ни один признак не может быть удалён из текущей модели.
