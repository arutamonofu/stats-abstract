Метод обратного отбора (backward removal) — пошаговый метод отбора признаков для построения регрессионной модели.

# Свойства

| Свойство         | Значение                         |
| :--------------- | :------------------------------- |
| Вид              | Пошаговый                        |
| Исходная модель  | Включает все доступные признаки. |
| Действие на шаге | Удаление одного признака.        |

# Методология

Сначала в пустую модель добавляются все доступные признаки. Затем пошагово к удалению рассматриваются признаки, соответствующие одному из критериев:

- наибольшее $p$-значение (из включённых в модель).
- наименьшее уменьшение $R^2$ при удалении.

Метод останавливается при выполнении одно из условий:

- Все оставшиеся (включённые в модель) признаки имеют $p$-значение, не превосходящее пороговое $\alpha_{\text{out}}$.
- Дальнейшее удаление признаков приводит к уменьшению $R^2$, превосходящему пороговое.
