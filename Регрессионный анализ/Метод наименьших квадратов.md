# Смысл

Найти оптимальную прямую линию (или другой функции), которая лучше всего приближает имеющиеся данные. Иными словами, минимизировать ошибки между предсказанными и реальными значениями, делая модель максимально точной.

# Принцип

Принцип основан на минимизации суммы квадратов (чтобы не учитывать знак) ошибок — разниц между предсказанными и фактическими значениями.

Простыми словами: мы измеряем, насколько точки «разбросаны» относительно прямой, и стараемся подобрать такую линию, при которой суммарный разброс (в квадрате) будет минимальным.

# Понятия

| Понятие                            | Объяснение                                               | Обозначение | Как найти                                                                                                                                                      |
| ---------------------------------- | -------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[Коэффициент корреляции Пирсона]] | Мера линейной связи между X и Y.                         | $r_{xy}$    | $\frac{{cov}_{xy}}{\sigma_{x}\sigma_{y}}$<br><br>или<br><br>$\frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum (X_i - \bar{X})^2 \sum (Y_i - \bar{Y})^2}}$ |
| Стандартное отклонение X           | Стандартное отклонение X.                                | $SD_x$      | $\sqrt{\frac{\sum (X_i - \bar{X})^2}{n}}$                                                                                                                      |
| Стандартное отклонение Y           | Стандартное отклонение Y.                                | $SD_y$      | $\sqrt{\frac{\sum (Y_i - \bar{Y})^2}{n}}$                                                                                                                      |
| Коэффициент наклона                | Показывает, насколько изменяется Y при изменении X на 1. | $b_{1}$     | $\frac{SD_{y}}{SD_{x}} \cdot r_{xy}$<br><br>или<br><br>$\frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sum (X_i - \bar{X})^2}$                                    |
| Свободный член                     | Отвечает за сдвиг линии, значение Y при X = 0.           | $b_{0}$     | $\overline{Y} - b_{1} \cdot \overline{X}$                                                                                                                      |
# Алгоритм

1. Рассчитать $SD_{x}$, $SD_{y}$.
2. Рассчитать $r_{xy}$.
3. Рассчитать $b_{1}$.
4. Рассчитать $b_{0}$.
