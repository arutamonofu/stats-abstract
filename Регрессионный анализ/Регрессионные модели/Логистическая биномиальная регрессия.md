# Моделирование

Логистическая функция вероятности:

$$\hat{P}(Y=1 | X_1, \dots, X_p) = \frac{1}{1 + e^{-(\hat{\beta_0} + \hat{\beta_1} X_1 + \hat{\beta_2} X_2 + \dots + \hat{\beta_p} X_p)}}$$

Логарифм шансов (логит):

$$\text{logit}(\hat{P}) = \ln\left(\frac{\hat{P}}{1-\hat{P}}\right) = \hat{\beta_0} + \hat{\beta_1} X_1 + \hat{\beta_2} X_2 + \dots + \hat{\beta_p} X_p$$

Где:

* $Y$ — зависимая бинарная переменная (принимает значения 0 или 1).
* $\hat{P}$ — предсказанная вероятность того, что $Y=1$.
* $X_1, X_2, \dots, X_p$ — независимые переменные (предикторы).
* $\hat{\beta_0}$ — оценочный свободный член, или интерцепт.
* $\hat{\beta_1}, \hat{\beta_2}, \dots, \hat{\beta_p}$ — оценочные коэффициенты регрессии.
* $p$ — количество независимых переменных.

## Вычисление $\hat{\beta_i}$

Коэффициенты $\hat{\beta_0}, \hat{\beta_1}, \dots, \hat{\beta_p}$ вычисляются [методом максимального правдоподобия]([Метод максимального правдоподобия — Википедия](https://ru.wikipedia.org/wiki/%D0%9C%D0%B5%D1%82%D0%BE%D0%B4_%D0%BC%D0%B0%D0%BA%D1%81%D0%B8%D0%BC%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%B3%D0%BE_%D0%BF%D1%80%D0%B0%D0%B2%D0%B4%D0%BE%D0%BF%D0%BE%D0%B4%D0%BE%D0%B1%D0%B8%D1%8F)) (ММП), методами оптимизации:

- градиентный подъём,
- метод Ньютона-Рафсона,
- итеративно взвешиваемый метод наименьших квадратов (IRLS).

# Пример

Мы хотим предсказать, сдаст ли студент экзамен ($Y = 1$ — сдал, $Y = 0$ — не сдал) на основе среднего балла за предыдущие семестры ($X_1$). Были собраны данные по 6 студентам:

| #  | Сдал экзамен ($Y$) | Средний балл за прошлые семестры ($X_1$) |
|----|------------------|-----------|
| 1  | 0              | 2.7       |
| 2  | 1              | 3.6       |
| 3  | 0              | 2.9       |
| 4  | 1              | 3.8       |
| 5  | 0              | 2.6       |
| 6  | 1              | 3.3       |
| 7  | 0              | 3.0       |
| 8  | 1              | 3.9       |
| 9  | 0              | 2.7       |
| 10 | 1              | 3.4       |
| 11 | 0              | 2.9       |
| 12 | 1              | 3.6       |
| 13 | 0              | 3.1       |
| 14 | 1              | 3.2       |
| 15 | 0              | 2.5       |
| 16 | 1              | 3.1       |
| 17 | 0              | 3.2       |
| 18 | 1              | 2.8       |
| 19 | 0              | 3.4       |
| 20 | 1              | 2.9       |

Задачи:

1.  Смоделировать логистическую регрессию.
2.  Определить значимость модели и коэффициентов при $\alpha = 0.05$.
3.  Оценить предварительное качество модели, используя псевдо-$R^2$.

Решение:

1. Допустим, после применения ММП, мы получили следующие коэффициенты:
	- $\hat{\beta}_0 = -8.5$, $\hat{\beta}_1 = 1.2$, $\hat{\beta}_2 = 1.5$.

2. Запишем уравнение регрессии:
	- $\text{logit}(\hat{P}) = \ln\left(\frac{P}{1-P}\right) = -8.5 + 1.2X_1 + 1.5X_2$
	- $\hat{P}(Y=1) = \frac{1}{1 + e^{-(-8.5 + 1.2 X_1 + 1.5 X_2)}}$

3. Для проверки значимости модели сформулируем $H_{0}$, рассчитаем $\chi^2$, найдём $p$ и сравним с $\alpha$:
	- $H_{0} : \beta_{1} = \beta_{2} = 0$
	- $\chi^2 = 7.2$
	- $p = 0.027$
	- $p < \alpha$

4. Для проверки значимости коэффициентов сформулируем $H_{0}$, рассчитаем $t$, найдём $p$ и сравним с $\alpha$:
	- $H_{0} : \beta_{i} = 0$
	- Для $\hat{\beta_{0}}$: $t = -1.90$, $p = 0.057$, $p > \alpha$.
	- Для $\hat{\beta_{1}}$: $t = 2.15$, $p = 0.031$, $p < \alpha$.
	- Для $\hat{\beta_{2}}$: $t = 1.55$, $p = 0.121$, $p > \alpha$.

5. Рассчитаем $R^2$ МакФаддена:
	- $R^2_{МакФаддена} = 0.300$.

Ответ:

* Уравнение логистической регрессии:
	- $\text{logit}(\hat{P}) = -8.5 + 1.2X_1 + 1.5X_2$;
	- $\hat{P}(Y=1) = \frac{1}{1 + e^{-(-8.5 + 1.2 X_1 + 1.5 X_2)}}$.
* На уровне значимости $\alpha=0.05$ модель значима, коэффициент при переменной «Часы подготовки» значим, интерцепт и коэффициент при «GPA» не являются значимыми.
* Модель имеет умеренное качество, $R^2_{МакФаддена} = 0.300$.
