# Моделирование

$$\hat{Y} = \hat{\beta_{0}} + \hat{\beta_{1}}X$$

Где:

- $\hat{Y}$ — зависимая переменная;
- $X$ — независимая переменная, или предиктор;
- $\hat{\beta_{0}}​$ — свободный член, или интерцепт;
- $\hat{\beta_1}​$ — коэффициент наклона, или слоуп.

## Вычисление $\hat{\beta_{i}}$

Вычисление $\hat{\beta_{0}}$, $\hat{\beta_{1}}$ [методом наименьших квадратов](https://ru.wikipedia.org/wiki/%D0%9C%D0%B5%D1%82%D0%BE%D0%B4_%D0%BD%D0%B0%D0%B8%D0%BC%D0%B5%D0%BD%D1%8C%D1%88%D0%B8%D1%85_%D0%BA%D0%B2%D0%B0%D0%B4%D1%80%D0%B0%D1%82%D0%BE%D0%B2):

$$\hat{\beta_{1}} = \frac{SD_{y}}{SD_{x}} \cdot r_{xy}$$

Или:

$$\hat{\beta_{1}} = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sum (X_i - \bar{X})^2}$$

$$\hat{\beta_{0}} = \bar{Y} - b_{1} \cdot \bar{X}$$

# Пример

На химическом предприятии изучается зависимость выхода целевого продукта (%) от температуры реакции (°C) в реакторе. Инженер-технолог предполагает, что повышение температуры должно приводить к увеличению выхода продукта, хочет количественно оценить эту зависимость и построить прогностическую модель. Были собраны данные по 10 партиям:

| Партия | Температура, $X$ | Выход продукта, $Y$ |
| :----- | :--------------- | :------------------ |
| 1      | 150              | 75                  |
| 2      | 155              | 70                  |
| 3      | 160              | 80                  |
| 4      | 165              | 78                  |
| 5      | 170              | 90                  |
| 6      | 175              | 85                  |
| 7      | 180              | 95                  |
| 8      | 185              | 88                  |
| 9      | 190              | 100                 |
| 10     | 195              | 92                  |

Задачи:

1. Смоделировать линейную регрессию.
2. Определить значимость модели и коэффициентов при $\alpha = 0.05$.
3. Оценить предварительное качество модели, рассчитав $R^2$ на тренировочных данных.

Решение:

1.  Рассчитаем необходимые суммы и средние:
    *   $x = [150, 155, 160, 165, 170, 175, 180, 185, 190, 195]$
    *   $y = [75, 70, 80, 78, 90, 85, 95, 88, 100, 92]$
    *   $\sum x_i = 1725$
    *   $\sum y_i = 853$
    *   $\bar{x} = \frac{1725}{10} = 172.5$
    *   $\bar{y} = \frac{853}{10} = 85.3$
    *   $\sum x_i^2 = 150^2 + \dots + 195^2 = 299625$
    *   $\sum y_i^2 = 75^2 + \dots + 92^2 = 73567$
    *   $\sum x_i y_i = (150 \cdot 75) + \dots + (195 \cdot 92) = 148265$

2.  Рассчитаем $\hat{\beta_1}$, $\hat{\beta_{0}}$:
	- $\hat{\beta_1} = \frac{10 \cdot 148265 - (1725 \cdot 853)}{10 \cdot 299625 - (1725)^2} = \frac{1482650 - 1471425}{2996250 - 2975625} = \frac{11225}{20625} \approx 0.544$
	- $\hat{\beta_0} = 85.3 - 0.544 \cdot 172.5 \approx 85.3 - 93.84 \approx -8.54$

3. Запишем уравнение регрессии:
	- $\hat{Y} = -8.54 + 0.544X$

4.  Сформулируем $H_{0}$ для $\hat{\beta_1}$:
    * $H_0: \beta_1 = 0$ (температура реакции не оказывает линейного влияния на выход продукта).

5. Найдём $p$:
	- $p$ для t-критерия Стьюдента для коэффициента регрессии примерно равно $0.001$.

6. Сравним $p$ и $\alpha$:
	- $0.001 < 0.05$.

Вывод: на уровне значимости $\alpha$ существует положительная линейная связь между температурой реакции и выходом продукта. Уравнение регрессии: $\hat{Y} = -8.54 + 0.544X$.

## Python

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from statsmodels.api import OLS
import matplotlib.pyplot as plt


# Вводные

data = pd.DataFrame({
    "Выход продукта": [75, 70, 80, 78, 90, 85, 95, 88, 100, 92],
    "Температура": [150, 155, 160, 165, 170, 175, 180, 185, 190, 195],
})
alpha = 0.05


# 1. Моделирование линейной регрессии

y = data["Выход продукта"]
x = data[["Температура"]]

model = LinearRegression()
model.fit(x, y)

print(f"Уравнение регрессии: Ŷ = {model.intercept_:.2f}", end="")
for i, coef in enumerate(model.coef_):
    print(f" + ({coef:.2f} ⋅ X{i + 1})", end="")
print("\n")


# 2. Проверка значимости модели и коэффициентов

sm_model = OLS(y, add_constant(x)).fit()

if (sm_model.f_pvalue) < alpha:
    print(
        "Проверка значимости модели: "
        f"F = {sm_model.fvalue:.3f}, "
        f"p ({sm_model.f_pvalue:.3f}) < α ({alpha:.3f}) — "
        "модель значима."
    )
else:
    print(
        "\Проверка значимости модели: "
        f"p ({sm_model.f_pvalue:.3f}) ≥ α ({alpha:.3f}) — "
        "модель не значима."
    )

for i, coef_p in enumerate(sm_model.pvalues):
    print(f"Проверка значимости b{i}: t = {sm_model.tvalues.iloc[i]:.3f}, ", end="")
    if coef_p < alpha:
        print(
            f"p ({coef_p:.3f}) < α ({alpha:.3f}) — "
            "коэффициент отличается от 0."
        )
    else:
        print(
            f"p ({coef_p:.3f}) ≥ α ({alpha:.3f}) — "
            "коэффициент не отличается от 0."
        )
print()


# 3. Расчёт коэффициента детерминации

print(f"R² = {model.score(x, y):.3f}")


# Визуализация регрессии

plt.figure(figsize=(8, 5), dpi=100)
plt.grid(alpha=0.3)

plt.scatter(x, y, color="C7", label="Наблюдения")
plt.plot(x, model.predict(x), color="C4", label="Линия регрессии")

plt.xlabel("Температура")
plt.ylabel("Выход продукта")
plt.title("Линейная одномерная регрессия")
plt.legend()

plt.show()
```
