Регрессионная модель — математическая модель, которая описывает взаимосвязь между переменными, позволяя предсказывать значения зависимой переменной на основе значений независимых переменных.

| Модель                                       | Уравнение                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[Линейная одномерная регрессия]]            | $\hat{Y} = \hat{\beta_{0}} + \hat{\beta_{1}}X$                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| [[Линейная множественная регрессия]]         | $\hat{Y} = \hat{\beta_0} + \hat{\beta_1 X_1} + \hat{\beta_2} X_2 + \dots + \hat{\beta_p} X_p$                                                                                                                                                                                                                                                                                                                                                                                                     |
| [[Логистическая биномиальная регрессия]]     | $\hat{P}(Y=1 \| X_1, \dots, X_p) = \frac{1}{1 + e^{-(\hat{\beta_0} + \hat{\beta_1} X_1 + \hat{\beta_2} X_2 + \dots + \hat{\beta_p} X_p)}}$<br>$\text{logit}(\hat{P}) = \hat{\beta_0} + \hat{\beta_1} X_1 + \hat{\beta_2} X_2 + \dots + \hat{\beta_p} X_p$                                                                                                                                                                                                                                         |
| [[Логистическая мультиномиальная регрессия]] | $\hat{P}(Y=K\|X) = \frac{1}{1 + \sum_{k=1}^{K-1} e^{(\hat{\beta_{k0}} + \hat{\beta_{k1}}X_1 + \dots + \hat{\beta_{kp}}X_p)}}$<br>$\hat{P}(Y=j\|X) = \frac{e^{(\hat{\beta_{j0}} + \hat{\beta_{j1}}X_1 + \dots + \hat{\beta_{jp}}X_p)}}{1 + \sum_{k=1}^{K-1} e^{(\hat{\beta_{k0}} + \hat{\beta_{k1}}X_1 + \dots + \hat{\beta_{kp}}X_p)}}$<br>$\ln\left(\frac{\hat{P}(Y=j\|X)}{\hat{P}(Y=K\|X)}\right) = \hat{\beta_{j0}} + \hat{\beta_{j1}}X_1 + \hat{\beta_{j2}}X_2 + \dots + \hat{\beta_{jp}}X_p$ |
| [[Полиномиальная регрессия]]                 | $\hat{Y} = \hat{\beta_0} + \hat{\beta_1} X + \hat{\beta_2} X^2 + \dots + \hat{\beta_k} X^k$                                                                                                                                                                                                                                                                                                                                                                                                       |
