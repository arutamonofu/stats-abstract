# Моделирование

Одна из категорий зависимой переменной выбирается в качестве *референтной*. Для каждой из остальных категорий строится модель относительно референтной.

Пусть $K$ — количество категорий зависимой переменной. Выберем категорию $K$ в качестве референтной. Тогда для каждой категории $j \in \{1, 2, \dots, K-1\}$:

$$ \text{logit}(\hat{P}(Y=j|X)) = \ln\left(\frac{\hat{P}(Y=j|X)}{\hat{P}(Y=K|X)}\right) = \hat{\beta_{j0}} + \hat{\beta_{j1}}X_1 + \hat{\beta_{j2}}X_2 + \dots + \hat{\beta_{jp}}X_p $$

Вероятность выбора категории $j$ ($j \ne K$):

$$ \hat{P}(Y=j|X) = \frac{e^{(\hat{\beta_{j0}} + \hat{\beta_{j1}}X_1 + \dots + \hat{\beta_{jp}}X_p)}}{1 + \sum_{k=1}^{K-1} e^{(\hat{\beta_{k0}} + \hat{\beta_{k1}}X_1 + \dots + \hat{\beta_{kp}}X_p)}} $$

Вероятность выбора референтной категории $K$:

$$\hat{P}(Y=K|X) = \frac{1}{1 + \sum_{k=1}^{K-1} e^{(\hat{\beta_{k0}} + \hat{\beta_{k1}}X_1 + \dots + \hat{\beta_{kp}}X_p)}}$$

Где:

* $Y$ — зависимая категориальная переменная.
* $\hat{P}(Y=j|X)$ — предсказанная вероятность того, что $Y$ примет значение $j$, при заданных $X$.
* $X_1, X_2, \dots, X_p$ — независимые переменные (предикторы).
* $\hat{\beta_{j0}}$ — оценочный свободный член (интерцепт) для $j$-й категории относительно референтной.
* $\hat{\beta_{jk}}$ — оценочный коэффициент для $k$-й независимой переменной ($X_k$) для $j$-й категории относительно референтной.
* $p$ — количество независимых переменных.

### Вычисление $\beta_{ji}$

Коэффициенты $\hat{\beta_{j0}}, \hat{\beta_{j1}}, \dots, \hat{\beta_{jp}}$ для каждой из моделей вычисляются [методом максимального правдоподобия]([Метод максимального правдоподобия — Википедия](https://ru.wikipedia.org/wiki/%D0%9C%D0%B5%D1%82%D0%BE%D0%B4_%D0%BC%D0%B0%D0%BA%D1%81%D0%B8%D0%BC%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%B3%D0%BE_%D0%BF%D1%80%D0%B0%D0%B2%D0%B4%D0%BE%D0%BF%D0%BE%D0%B4%D0%BE%D0%B1%D0%B8%D1%8F)) (ММП), методами оптимизации:

*   градиентный подъём,
*   метод Ньютона-Рафсона,
*   итеративно взвешиваемый метод наименьших квадратов (IRLS).

### Пример

На основе данных о 25 пользователях (возраст; уровень дохода: «низкий», «средний», «высокий»; еженедельные часы просмотра) исследуйте факторы, влияющие на выбор одного из трех стриминговых сервисов: Netflix, Hulu или Disney+.

|  #  | Выбранный сервис ($Y$) | Возраст ($X_1$) | Часы просмотра в неделю ($X_2$) |
| :-: | :--------------------- | :-------------: | :-----------------------------: |
|  1  | Netflix                |       22        |               15                |
|  2  | Hulu                   |       35        |               10                |
|  3  | Disney+                |       45        |                5                |
|  4  | Netflix                |       18        |               20                |
|  5  | Netflix                |       28        |               12                |
|  6  | Disney+                |       50        |                8                |
|  7  | Hulu                   |       25        |                8                |
|  8  | Netflix                |       32        |               18                |
|  9  | Hulu                   |       41        |               10                |
| 10  | Disney+                |       19        |               12                |
| 11  | Disney+                |       60        |                3                |
| 12  | Netflix                |       29        |               22                |
| 13  | Hulu                   |       21        |                5                |
| 14  | Hulu                   |       38        |                7                |
| 15  | Netflix                |       48        |               15                |
| 16  | Netflix                |       20        |               18                |
| 17  | Disney+                |       33        |                9                |
| 18  | Hulu                   |       55        |                6                |
| 19  | Netflix                |       26        |               10                |
| 20  | Hulu                   |       30        |               14                |
| 21  | Netflix                |       42        |               12                |
| 22  | Disney+                |       23        |               16                |
| 23  | Netflix                |       37        |               20                |
| 24  | Disney+                |       49        |                7                |
| 25  | Hulu                   |       27        |                7                |

Задачи:

1.  Смоделировать мультиномиальную логистическую регрессию, референтная категория — Disney+.
2.  Определить значимость модели и коэффициентов при $\alpha = 0.05$.
3.  Оценить предварительное качество модели, используя псевдо-$R^2$.

### Решение:

1. Закодируем категории:
	- Hulu — 1;
	- Netflix — 2;
	- Disney+ — 0.
2. После применения ММП мы получили следующие коэффициенты относительно референтной категории:
    * Для 1:
        * $\hat{\beta}_{10} = 0.71$;
        * $\hat{\beta}_{11} = 0.02$;
        * $\hat{\beta}_{12} = -0.11$.
    * Для 2:
        * $\hat{\beta}_{20} = 4.02$;
        * $\hat{\beta}_{21} = -0.04$;
        * $\hat{\beta}_{22} = -0.24$.

3. Запишем уравнения регрессии:
    * $\text{logit}(\hat{P}(Y = 1 | X)) = 0.71 + 0.02X_1 - 0.11X_2$
    * $\text{logit}(\hat{P}(Y = 2 | X)) = 4.02 - 0.04X_1 - 0.24X_2$
    * $\hat{P}(Y = 0 | X) = \frac{1}{1 + e^{0.71 + 0.02X_1 - 0.11X_2} + e^{4.02 - 0.04X_1 - 0.24X_2}}$
    * $\hat{P}(Y = 1 | X) = \frac{e^{0.71 + 0.02X_1 - 0.11X_2}}{1 + e^{0.71 + 0.02X_1 - 0.11X_2} + e^{4.02 - 0.04X_1 - 0.24X_2}}$
    * $\hat{P}(Y = 2 | X) = \frac{e^{4.02 - 0.04X_1 - 0.24X_2}}{1 + e^{0.71 + 0.02X_1 - 0.11X_2} + e^{4.02 - 0.04X_1 - 0.24X_2}}$

4. Для проверки значимости модели сформулируем $H_{0}$, рассчитаем $\chi^2$, найдём $p$ и сравним с $\alpha$:
	- $H_{0} : \beta_{1} = \beta_{2} = 0$
	- $\chi^2 = 18.109$, $df = 4$
	- $p = 0.001$
	- $p < \alpha$

5. Для проверки значимости коэффициентов сформулируем $H_{0}$, рассчитаем $t$, найдём $p$ и сравним с $\alpha$.
	- Для 1:
		- $H_{0} : \beta_{1i} = 0$
		- Для $\hat{\beta_{10}}$: $t = 1.026$, $p = 0.305$, $p > \alpha$.
		- Для $\hat{\beta_{11}}$: $t = -1.085$, $p = 0.278$, $p > \alpha$.
		- Для $\hat{\beta_{12}}$: $t = -0.656$, $p = 0.512$, $p > \alpha$.
	- Для 2:
		- $H_{0} : \beta_{2i} = 0$
		- Для $\hat{\beta_{20}}$: $t = -1.286$, $p = 0.198$, $p > \alpha$.
		- Для $\hat{\beta_{21}}$: $t = 0.107$, $p = 0.915$, $p > \alpha$.
		- Для $\hat{\beta_{22}}$: $t = 2.126$, $p = 0.034$, $p < \alpha$.

6.  Рассчитаем $R^2$ МакФаддена:
    * $R^2_{\text{МакФаддена}} = 0.333$

Ответ:

* Уравнения логарифма шансов при референтной категории Disney+:
    * $\text{logit}(\hat{P}(Y = 1 | X)) = 0.71 + 0.02X_1 - 0.11X_2$
    * $\text{logit}(\hat{P}(Y = 2 | X)) = 4.02 - 0.04X_1 - 0.24X_2$
    * $\hat{P}(Y = 0 | X) = \frac{1}{1 + e^{0.71 + 0.02X_1 - 0.11X_2} + e^{4.02 - 0.04X_1 - 0.24X_2}}$
    * $\hat{P}(Y = 1 | X) = \frac{e^{0.71 + 0.02X_1 - 0.11X_2}}{1 + e^{0.71 + 0.02X_1 - 0.11X_2} + e^{4.02 - 0.04X_1 - 0.24X_2}}$
    * $\hat{P}(Y = 2 | X) = \frac{e^{4.02 - 0.04X_1 - 0.24X_2}}{1 + e^{0.71 + 0.02X_1 - 0.11X_2} + e^{4.02 - 0.04X_1 - 0.24X_2}}$
* На уровне значимости $\alpha = 0.05$ модель значима. Для категории Hulu все предикторы не значимы. Для категории Netflix часы просмотра в неделю — значимый предиктор, возраст — незначимый предиктор.
* Модель имеет среднее качество объяснения дисперсии: $R^2 _{\text{МакФаддена}} \approx 0.333$.

## Python

```python
import pandas as pd
from sklearn.linear_model import LogisticRegression
import statsmodels.api as sm

# Вводные

data = pd.DataFrame({
    "Сервис": ['Netflix', 'Hulu', 'Disney+', 'Netflix',
               'Netflix', 'Disney+', 'Hulu', 'Netflix',
               'Hulu', 'Disney+', 'Disney+', 'Netflix',
               'Hulu', 'Hulu', 'Netflix', 'Netflix',
               'Disney+', 'Hulu', 'Netflix', 'Hulu', 
               'Netflix', 'Disney+', 'Netflix', 'Disney+', 
               'Hulu'],
    "Возраст": [22, 35, 45, 18, 28, 50, 25, 32, 41, 19,
            60, 29, 21, 38, 48, 20, 33, 55, 26, 30,
            42, 23, 37, 49, 27],
    "Часы просмотра в неделю": [15, 10, 5, 20, 12, 8, 8, 18, 10, 12,
                             3, 22, 5, 7, 15, 18, 9, 6, 10, 14,
                             12, 16, 20, 7, 7]
})
alpha = 0.05


# 1. Моделирование мультиномиальной логистической регрессии

y = data.iloc[:, 0]
x = data.iloc[:, 1:]

model = LogisticRegression()
model.fit(x, y)

for i, class_ in enumerate(model.classes_[1:]):
    print(f"Уравнение регрессии для {class_} относительно {model.classes_[0]}:")
    print(f"logit(P) = {model.intercept_[i]:.2f}", end="")
    for j, coef in enumerate(model.coef_[i]):
        print(f" + ({coef:.2f} ⋅ X{j + 1})", end="")
    print("\n")


# 2. Проверка значимости модели и коэффициентов

sm_model = sm.MNLogit(y, sm.add_constant(x)).fit(disp=0)

if sm_model.llr_pvalue < alpha:
    print(
        f"Проверка значимости модели (LR): χ² = {sm_model.llr:.3f}, "
        f"p ({sm_model.llr_pvalue:.3f}) < α ({alpha:.3f}) — "
        "модель значима."
    )
else:
    print(
        "Проверка значимости модели: "
        f"p ({sm_model.llr_pvalue:.3f}) ≥ α ({alpha:.3f}) — "
        "модель не значима."
    )

for i, class_ in enumerate(model.classes_[1:]):
    print(f"Проверка значимости коэффициентов {class_} (относительно {model.classes_[0]}):")
    for predictor in sm_model.pvalues.index:
        t = sm_model.tvalues.loc[predictor, i]
        p = sm_model.pvalues.loc[predictor, i]
        if p < alpha:
                print(
                f"  '{predictor}': "
                f"t = {t:.3f}, p ({p:.3f}) < α ({alpha:.3f}) — "
                "отличается от 0."
                )
        else:
                print(
                f"  '{predictor}': "
                f"t = {t:.3f}, p ({p:.3f}) ≥ α ({alpha:.3f}) — "
                "не отличается от 0."
                )

print(f"\nR² МакФаддена = {sm_model.prsquared:.3f}")
```
