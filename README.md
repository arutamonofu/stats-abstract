Личные конспекты в Obsidian на тему распределений случайных величин и статистических тестов.

Распределения:

- биномиальное,
- гипергеометрическое,
- логнормальное,
- нормальное,
- Пуассона,
- Стьюдента,
- хи-квадрат,
- экспоненциальное.

Тесты:

- Критерий согласия хи-квадрат
- Критерий независимости хи-квадрат
- Критерий хи-квадрат МакНемара
- Точный тест Фишера
- Z-критерий для пропорций 1-выборочный
- Z-критерий равенства пропорций 2-выборочный
- t-критерий Стьюдента для 1 выборки
- t-критерий Стьюдента для 2 выборок
- t-критерий Стьюдента для двух связанных выборок
- t-критерий Уэлча для 2 выборок с разной дисперсией
- Дисперсионный анализ 1-факторный
- Дисперсионный анализ 2-факторный
- Тест Левене
- t-критерий Стьюдента для коэффициента корреляции Пирсона
